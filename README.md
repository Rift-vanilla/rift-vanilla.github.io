# Сайт Schalker Launcher

Статическая страница без сборки: `index.html`, картинки в `img/`, шрифт Rubik в `fonts/`.

Версия, размер и ссылка кнопки «Скачать», а также «Что нового» берутся в браузере из
последних релизов `Rift-vanilla/launcher-files` (файл `Rift-Launcher-Setup-<версия>.exe`).
После выпуска новой версии сайт обновлять не нужно.

Публикуется через GitHub Pages из ветки `main`. Свой домен — файл `CNAME` с именем домена.
